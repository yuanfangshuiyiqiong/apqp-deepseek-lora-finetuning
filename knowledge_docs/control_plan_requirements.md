# 控制计划要求

控制计划是 APQP 中用于描述产品和过程控制方法的重要文件。它应说明从来料、过程制造、检验测试到出货环节如何控制关键特性和质量风险。

控制计划通常应包含以下内容：过程步骤、产品特性、过程特性、特殊特性标识、控制方法、检验设备、样本容量、检验频率、责任岗位、记录方式和异常反应计划。

控制计划应与过程流程图和 PFMEA 保持一致。过程流程图描述制造步骤，PFMEA 识别每个步骤的潜在失效模式，控制计划则规定如何控制这些风险。如果三者不一致，说明 APQP 文件之间存在断点。

如果控制计划没有明确检验频率和责任岗位，可能导致以下问题：

1. 操作人员不知道何时检查和检查多少。
2. 质量责任不清，异常问题无法及时闭环。
3. 检验记录不完整，客户审核时难以证明过程受控。
4. 关键特性可能漏检，增加批量质量风险。

控制计划应在样件、试生产和量产阶段逐步完善。项目后期临时补控制计划不符合质量先期策划思想，因为关键风险应在过程开发阶段就被识别和控制。

当用户询问控制计划应包含哪些内容时，应从控制对象、控制方法、检验频率、责任岗位和异常反应计划几个方面回答。
