# FMEA 管理要求

FMEA 是 Failure Mode and Effects Analysis 的缩写，中文通常称为失效模式及影响分析。FMEA 的目的是系统识别潜在失效模式、分析失效后果和原因，并制定预防或探测措施。

在 APQP 中，FMEA 不是一次性文件，而是需要随着设计变更、过程变更、客户反馈、试生产问题和量产质量问题持续更新的动态风险管理工具。

如果项目只在初期做了 FMEA，后续没有更新，主要风险包括：

1. 新增设计风险无法及时识别。
2. 过程变更带来的新失效模式没有被纳入控制。
3. 试生产或客户反馈中的问题没有转化为预防措施。
4. 控制计划可能与实际风险不一致。
5. 量产后可能出现重复质量问题或客户投诉。

FMEA 应与过程流程图、控制计划、作业指导书和检验规范保持联动。若 PFMEA 中识别出关键失效模式，控制计划中应有对应的控制方法、检验频率和异常反应计划。

FMEA 评审建议至少在项目启动、设计冻结、工艺方案确定、试生产前、PPAP 提交前和重大变更后进行。评审时应确认高风险项是否已有责任人、完成期限和验证结果。

当用户询问 FMEA 不更新的影响时，应重点回答风险识别失效、控制措施滞后、控制计划不匹配和量产质量风险上升。
