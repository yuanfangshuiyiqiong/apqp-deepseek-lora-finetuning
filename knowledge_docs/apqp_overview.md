# APQP 基础说明

APQP 是 Advanced Product Quality Planning 的缩写，中文通常称为产品质量先期策划。它是一套用于新产品开发和量产准备的质量策划方法，核心目标是在项目早期识别风险、定义质量要求、建立过程控制，并确保产品在量产前具备稳定交付能力。

APQP 通常适用于汽车零部件、制造业新产品开发、客户定制项目、供应商开发和质量体系建设。它强调跨部门协同，常见参与角色包括项目经理、质量工程师、研发工程师、工艺工程师、采购、生产、供应商质量工程师和客户代表。

APQP 的价值在于把质量问题前移。项目团队不应等到试生产或量产后才发现问题，而应在产品设计、过程设计、样件验证、试生产和量产批准之前持续识别风险并采取预防措施。

常见 APQP 输出包括项目计划、客户特殊要求识别、设计评审记录、DFMEA、过程流程图、PFMEA、控制计划、测量系统分析、初始过程能力研究、试生产总结、PPAP 提交资料和经验教训总结。

当用户询问“APQP 是什么”时，应说明它是产品质量先期策划方法，重点围绕质量策划、风险预防、过程控制和量产准备展开，而不是只解释为普通项目管理流程。
